第五部分  

全流程智能库存管理

从入库到出库，从核算到预警，构建闭环式中药房数字化管理体系。

核心能力

- 智能入库：支持手动录入或 Excel 批量导入，内置药品编码智能纠错  
- 精准出库：处方解析自动匹配库存，一键生成出库单  
- 经方知识库：收藏、搜索、导入经典方剂，自动拆解为药品清单  
- 自主开方模式：无需AI介入，直接在出库界面组合药品生成处方

第七部分  

跨终端处方协同共享

打通诊室与药房信息孤岛，实现“开方即达、无需打印”的高效协同。

- 启用本地文件共享服务（默认端口可配置）  
- 药房端通过 Android 客户端连接（安装包内置于软件压缩包）  
- 输入服务器 IP 与端口（如 192.168.1.100:8080），实时接收新处方  
- 降低沟通成本，提升配药准确率与响应速度
